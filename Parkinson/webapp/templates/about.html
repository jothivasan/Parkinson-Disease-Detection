About This Project

This is an AI-powered diagnostic assistance system that analyzes brain MRI scans to detect patterns associated with Parkinson's Disease. Developed as a final-year academic project, it demonstrates the application of deep learning in medical imaging.

How It Works

1

Image Upload

User uploads a brain MRI scan through the web interface

2

Preprocessing

Image is resized to 224×224 pixels and normalized for CNN input

3

CNN Analysis

Convolutional Neural Network extracts features and classifies the image

4

Result Display

Prediction (Healthy/Parkinson) with confidence score is displayed

CNN Model Architecture

Our model uses a custom Convolutional Neural Network designed for MRI analysis:

Layer Configuration Purpose
Input 224 × 224 × 3 Accepts preprocessed MRI images
Conv Block 1 32 filters, 3×3 Detects basic patterns (edges, gradients)
Conv Block 2 64 filters, 3×3 Learns intermediate features
Conv Block 3 128 filters, 3×3 Captures structural patterns
Conv Block 4 256 filters, 3×3 Maximum feature abstraction
Dense 256 units, ReLU Feature combination
Dropout 50% Prevents overfitting
Output 1 unit, Sigmoid Binary classification probability

Academic Information

This project demonstrates the following concepts for academic evaluation:

  • Deep Learning: CNN architecture design and implementation
  • Medical Image Analysis: MRI preprocessing and feature extraction
  • Binary Classification: Supervised learning for disease detection
  • Data Handling: Class imbalance handling and data augmentation
  • Web Development: Flask-based user interface
  • Model Evaluation: Metrics interpretation and visualization
